# Revised game direction

Chinese is the puzzle material. Navigation is Play, Sets, Boosts, Cycle. Script, pinyin and translation direction controls live in Settings. Collectible cards and boost labels have no dictionary glosses. English answers and clues remain available in translation puzzles.

## Production

Each set contributes: sum of owned card rates × set-completion multiplier × applicable chain multipliers. Add set contributions, then apply global boosts and cycle multiplier. Apply a chain only to its matching cards before summing. The dashboard can show the effective combined set multiplier as a compact summary.

Example completion milestones: 5/25 gives ×1.1, 10/25 ×1.3, 15/25 ×1.6, 20/25 ×2.0, and 25/25 ×3.0. Different-sized sets use their own thresholds. Unique cards advance completion; duplicates improve card levels rather than inflate the set count.

Correct matches build combo multipliers for active rewards. Completing rounds awards cards. Card-order puzzles unlock equipable sentence chains that multiply matching card production. Limited chain slots introduce loadout choices. Cycle rewards add permanent multipliers and more chain slots.

Points buy boosts, additional set access and puzzle tiers. Unlocked sets alternate word blocks and combinations. Purchases unlock access; puzzle success supplies cards. Keep active rewards meaningful as passive output grows.

## Screen flow

Dashboard → matching puzzle → dedicated card reward → dashboard or another round.

Dashboard → card-order puzzle → dedicated chain reward → equip or continue.

Sets shows compact collection grids and completion milestones. Boosts shows 8 rows and scrolls for more, with enabled Buy buttons only when affordable. Cycle shows permanent rewards and exactly what resets. Settings contains language and audio preferences.

Screenshot values are illustrative snapshots, not one consecutive session. This is a visual concept, not an implemented or balanced game.
