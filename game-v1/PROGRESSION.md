# Journey requirements

Finish the current lesson set, then meet the following village goals to advance to the next core level. Sentence and resource lessons remain part of the required lesson sequence.

- Buildings: count every purchased copy, including supply buildings, warehouses and duplicates. There is no per-type limit.
- Tech: count completed research plans, one per plan, across any path.
- Resources: hold all listed amounts simultaneously. These are stockpile checks, not fees; advancing consumes nothing. Spending resources before advancing can make a target incomplete again.
- Existing saves use their actual building counts, research and stored resources immediately.
- Timber and stone targets over base storage require a warehouse (available from level 2). Bricks and insight start at level 8 when their production unlocks.
